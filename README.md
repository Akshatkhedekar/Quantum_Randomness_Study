# True Randomness Experiment

> An experiment project to demonstrate "true" randomness of quantum computers.

##  Overview

Classical computers are deterministic—they generate **pseudorandom numbers** using mathematical algorithms that can be predicted or reverse-engineered. Quantum mechanics, however, is fundamentally unpredictable at the subatomic level.

This project compares **classical pseudorandom** vs. **quantum true random** number generation using:
- Python’s standard `random` library
- IBM Qiskit’s simulated qubit in superposition

##  The Impact on Cybersecurity

- Pseudorandomness can be hacked or predicted by modern AI/ML models
- True quantum randomness is the future of **unbreakable cryptography** and **quantum-safe cybersecurity**

##  Research Workflow

1. **Generate classical pseudorandom dataset**  
   Using Python's `random` module

2. **Generate quantum random dataset**  
   Using Qiskit to measure a qubit in superposition

3. **Analyze & visualize distributions**  
   Compare histograms, entropy, and statistical randomness tests

4. **Explain quantum randomness**  
   Why measurement collapse in superposition is physically random, not mathematically deterministic
